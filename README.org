Asynchronous GitHub radar for GNU Emacs. Tracks open issues, pull requests, and unread notifications across monitored repositories via the =gh= CLI and GraphQL, with mode-line indicators, desktop notifications, and dashboard.

** What's Inside

- *Mode-line Indicators:* Live counters for notifications, issues, and PRs.
- *Asynchronous Polling:* Background fetching and single-shot batched GraphQL.
- *Interactive Dashboard* (~M-x gh-radar-dashboard~): Overview with keyboard navigation, and unread item tracking.
- *Settings Buffer* (~M-x gh-radar-settings~): Repository management, customization, and toggleable modes persisted across sessions.
- *Desktop Notifications:* System notifications via D-Bus (=notifications-notify=) or =notify-send= when new issues or PRs arrive.
- *Error and Offline Detection:* Status indicator in mode-line and dashboard when connectivity fails or API errors occur.
- *GitHub Enterprise Support:* Configurable host target for GHE instances.

** Installation

*** Requirements
- GNU Emacs 27.1 or newer.
- [[https://cli.github.com/][GitHub CLI (~gh~)]] installed and authenticated (~gh auth login~).
- Optional: [[https://github.com/rainstormstudio/nerd-icons.el][nerd-icons.el]] for glyph icons (falls back to ASCII / Unicode characters automatically).

*** use-package with built-in :vc
#+begin_src elisp
  (use-package gh-radar
    :vc (:url "https://github.com/szymonwilczek/gh-radar.el" :branch "main")
    :demand t
    :config
    (gh-radar-mode 1))
#+end_src

*** straight.el
#+begin_src elisp

    :config
    (gh-radar-mode 1))
#+end_src

** Configuration Example

#+begin_src elisp
  (use-package gh-radar
    :vc (:url "https://github.com/szymonwilczek/gh-radar.el" :branch "main")
    :demand t
    :custom
    ;; Polling and backend
    (gh-radar-interval 300)                                ;; Poll every 5 minutes (default: 600)
    (gh-radar-github-host "github.com")                    ;; "github.com" or GHE host
    (gh-radar-recent-items-limit 10)                       ;; Max recent items per repo (default: 10)
    (gh-radar-desktop-notification-backend 'notifications) ;; 'notifications (D-Bus), 'notify-send, or nil
    (gh-radar-notify-on-new t)                             ;; Echo message on increments

    ;; Mode-line appearance
    (gh-radar-count-display 'all)                          ;; 'all (total + delta) or 'only-new (+delta)
    (gh-radar-bell-modeline nil)                           ;; t = single aggregate bell counter
    (gh-radar-hide-zero-counts '(inbox))                   ;; Hide 0 inbox counter; or t to hide all zeros
    (gh-radar-show-prefix nil)                             ;; Hide GitHub icon prefix

    ;; UI display style
    (gh-radar-dashboard-display-style 'full-window)        ;; 'full-window, 'same-window, or 'pop-to-buffer
    :config
    (gh-radar-mode 1))
#+end_src

** Mode-line Setup

If your mode-line does not automatically evaluate minor mode segments, add ~gh-radar-modeline-format~ explicitly:

#+begin_src elisp
  (add-to-list 'mode-line-format '(:eval (gh-radar-modeline-format)) t)
#+end_src

** Options and Variables

*** General and Polling Engine
| Variable                              | Default                  | Description                                                        |
|---------------------------------------+--------------------------+--------------------------------------------------------------------|
| ~gh-radar-interval~                     | ~600~                      | Background polling interval in seconds.                            |
| ~gh-radar-github-host~                  | ~"github.com"~             | Target GitHub host (supports GitHub Enterprise Server).            |
| ~gh-radar-gh-executable~                | ~"gh"~                     | Command name or path to the GitHub CLI binary.                     |
| ~gh-radar-cache-file~                   | ~".../gh-radar-cache.eld"~ | Path to persistent configuration and seen-item disk cache.         |
| ~gh-radar-recent-items-limit~           | ~10~                       | Max recent issues and PRs fetched per repository.                  |
| ~gh-radar-notify-on-new~                | ~t~                        | Display echo area notification when count increases.               |
| ~gh-radar-desktop-notification-backend~ | ~nil~                      | System notification backend: ~'notifications~, ~'notify-send~, or ~nil~. |

*** Dashboard and Interface
| Variable                         | Default      | Description                                                             |
|----------------------------------+--------------+-------------------------------------------------------------------------|
| ~gh-radar-dashboard-display-style~ | ~'full-window~ | Display mode: ~'full-window~ (maximize), ~'same-window~, or ~'pop-to-buffer~. |
| ~gh-radar-dashboard-max-width~     | ~100~          | Maximum column width of the dashboard layout.                           |
| ~gh-radar-count-display~           | ~'all~         | Count mode: ~'all~ (total + delta) or ~'only-new~ (+delta only).            |

*** Mode-line Presentation
| Variable                     | Default                 | Description                                                   |
|------------------------------+-------------------------+---------------------------------------------------------------|
| ~gh-radar-show-prefix~         | ~nil~                     | Display GitHub logo prefix before mode-line counters.         |
| ~gh-radar-bell-modeline~       | ~nil~                     | Aggregate all counters into a single bell icon and total sum. |
| ~gh-radar-hide-zero-counts~    | ~nil~                     | Hide zero segments: ~t~ (all), list e.g. ~'(inbox)~, or ~nil~.      |
| ~gh-radar-track-notifications~ | ~t~                       | Track unread notifications from GitHub inbox.                 |
| ~gh-radar-modeline-icons~      | ~'(inbox issues pr bell)~ | Enabled mode-line icon identifiers.                           |
| ~gh-radar-show-inbox-icon~     | ~t~                       | Display inbox icon in mode-line.                              |
| ~gh-radar-show-issue-icon~     | ~t~                       | Display issues icon in mode-line.                             |
| ~gh-radar-show-pr-icon~        | ~t~                       | Display pull requests icon in mode-line.                      |
| ~gh-radar-show-bell-icon~      | ~t~                       | Display bell icon in aggregate mode-line mode.                |

** Interactive Commands

| Command                           | Description                                                                |
|-----------------------------------+----------------------------------------------------------------------------|
| ~M-x gh-radar-dashboard~            | Open the interactive dashboard buffer (=*gh-radar*=).                        |
| ~M-x gh-radar-settings~             | Open repository and options settings buffer (=*gh-radar-settings*=).         |
| ~M-x gh-radar-refresh~              | Trigger immediate asynchronous GraphQL fetch for all tracked repositories. |
| ~M-x gh-radar-toggle-count-display~ | Toggle between displaying all counts and only new delta counts.            |
| ~M-x gh-radar-mode~                 | Global minor mode managing background timer and mode-line segment.         |
| ~?~ (in dashboard or settings)      | Open side-window popup displaying full keyboard bindings and navigation.   |
