#+TITLE: gh-radar.el
#+AUTHOR: Szymon Wilczek

Tracks open issue, pull request counts, and unread notifications using the =gh= CLI.

* Installation

#+begin_src elisp
(use-package gh-radar
  :load-path "~/Documents/GitHub/gh-radar.el"
  :config
  (gh-radar-mode 1))
#+end_src

Monitored repositories and tracking settings are managed interactively in the
Settings buffer (=s= in the dashboard or =M-x gh-radar-settings=) and persisted
automatically in =gh-radar-cache-file= across sessions.

* Configuration

- =gh-radar-cache-file=: Path to persistent configuration and disk cache file (default: =gh-radar-cache.eld= in user-emacs-directory).
- =gh-radar-count-display=: Display mode for counts in mode-line and dashboard: ='all= (total + new delta) or ='only-new= (only unread delta counts) (default: ='all=).
- =gh-radar-dashboard-display-style=: Display style for dashboard and settings buffer: ='full-window=, ='same-window=, or ='pop-to-buffer= (default: ='full-window=).
- =gh-radar-show-prefix=: Display GitHub prefix icon before counters (default: =nil=).
- =gh-radar-bell-modeline=: Replace all mode-line counters with a single aggregate bell icon and total sum (default: =nil=).
- =gh-radar-show-bell-icon=: Display bell icon in aggregate mode (default: =t=).
- =gh-radar-show-inbox-icon=: Display inbox icon in mode-line (default: =t=).
- =gh-radar-show-issue-icon=: Display issues icon in mode-line (default: =t=).
- =gh-radar-show-pr-icon=: Display pull requests icon in mode-line (default: =t=).
- =gh-radar-modeline-icons=: Set of icons to display in mode-line (default: ='(inbox issues pr bell)=).
- =gh-radar-hide-zero-counts=: Hide mode-line segments with zero count: =t= (all), list like ='(inbox)=, or =nil= (default: =nil=; zero counts are not hidden).
- =gh-radar-recent-items-limit=: Number of recent issues and PRs fetched per repository (default: 10).
- =gh-radar-interval=: Background polling frequency in seconds (default: 600).
- =gh-radar-gh-executable=: Path to =gh= binary (default: ="gh"=).
- =gh-radar-desktop-notification-backend=: Backend for desktop system notifications: ='notifications= (D-Bus / =notifications-notify=), ='notify-send= (external binary), custom function, or =nil= (default: =nil=).
- =gh-radar-notify-on-new=: Echo notification on count increments (default: =t=).
- =gh-radar-icons=: Alist mapping item types to nerd-icon names or unicode glyphs (persisted across sessions).

* Mode-line

#+begin_src elisp
(add-to-list 'mode-line-format '(:eval (gh-radar-modeline-format)) t)
#+end_src

* Commands

- =gh-radar-dashboard=: Open dedicated interactive dashboard buffer.
- =gh-radar-settings= (=s= in dashboard): Open interactive settings sub-buffer to manage monitored repositories and tracking options:
  - =a=: Add repository (=owner/name=) with automatic verification.
  - =i=: Toggle issues tracking for repository at point.
  - =p=: Toggle pull requests tracking for repository at point.
  - =d= / =x=: Delete repository from tracking.
  - =n=: Toggle GitHub notifications inbox tracking.
  - =c=: Toggle modeline count display mode (='all= vs ='only-new=).
  - =b=: Toggle aggregate modeline bell mode.
  - =z=: Cycle zero counts hiding mode (disabled, all, inbox only).
  - =I= (or =RET= on row): Interactively customize icon glyphs with candidate completion.
  - =q= / =s=: Save and return to dashboard.
- =gh-radar-toggle-count-display=: Toggle between displaying all counts and only new delta counts.
- =gh-radar-dashboard-dismiss= (=d= / =x=): Dismiss unread item or all unread items for repository.
- =gh-radar-dashboard-dismiss-all= (=D= / =X=): Dismiss all unread activity across all repositories.
- =gh-radar-dashboard-open-notifications=: Open GitHub notifications in browser.
- =gh-radar-refresh=: Trigger asynchronous API query.
- =gh-radar-browse=: Open repository issues or pull requests in browser.
